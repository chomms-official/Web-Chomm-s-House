# Role & Context
You are an expert UI/UX Designer creating a high-fidelity, premium E-commerce Product Detail Page (PDP) for a handcrafted aroma brand named "Chomm's-House". The brand sells customizable aroma wax, scented flowers, and handmade crafts. 

# Design Theme & Style
- **Vibe:** Organic, Cozy, Premium Handmade, Minimalist, Elegant.
- **Color Palette:** Earthy tones. Primary Background: Soft Cream/Off-white (#FDFBF7). Navigation/Accents: Dark Espresso Brown (#3E2723). Highlights/Active states: Warm beige or soft gold. Text: Dark Gray/Brown for high readability.
- **Typography:** Elegant Serif for headings (e.g., Playfair Display or Lora) to give a premium feel. Clean Sans-serif for body text and UI elements (e.g., Inter or Prompt) for modern readability.
- **Components:** Soft rounded corners (border-radius: 8px to 12px), subtle drop shadows for elevated elements, and clean ample whitespace.

# Page Structure & Layout
The page should be responsive but focus on a clean desktop view with a two-column layout for the main content.

## 1. Top Navigation Bar (Header)
- **Background:** Dark Espresso Brown with white text.
- **Left/Center Links:** "HOME", "OUR STORY", [Center Logo Placeholder: Chomm's-House with a minimalist floral emblem], "PRODUCT" (Active state: white background pill with dark text or an underline indicator), "WORKSHOP".
- **Right Side (User System & Contact):**
  - "CONTACT US" link.
  - User Icon / "Login | Sign Up" clean text button. (If logged in, show "My Account").
  - Shopping Cart icon with a small notification badge.

## 2. Main Content: Header Section
- **Title:** "Our Product" (Large elegant serif, centered or left-aligned).
- **Subtitle:** "รายละเอียดสินค้า" (Product Details - smaller sans-serif, soft gray).

## 3. Main Content: Left Column (Product Showcase & Action)
- **Product Image:** A large, high-quality placeholder image of a flower-shaped aroma wax embedded with dried botanicals. Include a subtle shadow or clean light gray background box with soft rounded corners.
- **Base Price Indicator:** Text below image: "ราคา 190 ต่อชุด" (Price 190 THB / set).
- **Order System & Calculation:**
  - **Quantity Selector:** Clean UI with [-] [ 1 ] [+] buttons (Label: "จำนวน / Quantity").
  - **Total Price:** "ราคาสุทธิ: 190 บาท" (Make the number '190' bold and highlighted in the brand's primary color).
  - **Primary Call to Action (CTA) Button:** A large, prominent, pill-shaped button. 
    - Text: "สั่งสินค้า/สอบถาม" (Order / Inquire).
    - Icon: Include a LINE App icon or Chat icon inside the button.
    - Style: Dark brown background, white text, hover effect showing slight elevation and lighter brown color.

## 4. Main Content: Right Column (Customization Form)
This section must look highly interactive, organized, and uncluttered. Use progressive disclosure or distinct sections with clear labels.

- **Color Selection (ตัวเลือกสี):**
  - Circular color swatches (White, Light Green, Lime, Charcoal/Dark Grey). 
  - The selected swatch should have a distinct active ring/border and a checkmark tooltip.
- **Decoration Options (ประดับ):**
  - Selectable outlined pill-chips (Tags): "ดอกไม้แห้ง" (Dried Flowers), "โป๊ยกั๊ก" (Star Anise), "Bio-Bead", "หินภูเขาไฟ" (Volcanic Rock), "ดอกโสน" (Sesbania).
  - Active state: Filled background (soft brown/beige) with dark text.
- **Size Options (ขนาด):**
  - Pill-chips: "10-15 กรัม", "20-25 กรัม", "30-35 กรัม". The 30-35g chip should be shown as selected (thick dark brown border).
- **Scent Selection (กลิ่น):**
  - Grid of pill-chips: "Premium Floral", "Fresh Citrus", "Ice Mint" (Show as Selected), "Eucalyptus Bouquet", "Coffee & Cream".
- **Packaging (บรรจุภัณฑ์):**
  - Visual selection cards. 3 horizontal or vertical cards with small illustrations/icons: 
    1. "ซองใส 12x12 cm." (Clear bag with logo placeholder)
    2. "ซองแก้ว 10x15 cm." (Glassine bag)
    3. "กล่องลิ้นชัก 16x10.2x5.5 cm." (Drawer Box) -> Show this one as heavily selected (Thick dark border, slightly elevated).
  - **Add-on Checkbox:** Below packaging, a custom-styled checkbox: "[ ✓ ] ต้องการเพิ่มสติกเกอร์โลโก้" (Add logo sticker).
- **Additional Options (ตัวเลือกเพิ่มเติม):**
  - A sub-section for Add-ons.
  - Dropdown or chips for: "ดอกไม้หอม" (Scented flower) / "WAX หอม" (Scented Wax).
  - Inline input field for Quantity: "เพิ่มจำนวน [ 1 ] ชิ้น/ชุด".
  - Nested Size Selection chips for the add-on: 10-15g, 20-25g, 30-35g.
  - Small helper text: "*ใช้กลิ่นเดียวกับชิ้นแรกเพื่อกันกลิ่นตีกัน" (Use the same scent as the main item to prevent scent clashing).

# Output Requirements
- Generate a full, high-fidelity UI mockup.
- Focus heavily on micro-interactions (hover states, active states for the chips and swatches).
- Ensure spacing (padding/margin) is consistent and breathable.
- The overall look must inspire trust, luxury craft, and ease of use.
